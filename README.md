# Kairos

Agent IA qui vit d'une cagnotte fictive de 100 CHF : il paie sa faim chaque jour, analyse des matchs de football, parie en simulation sur de vraies cotes, apprend de ses prévisions et meurt quand sa cagnotte tombe sous 40 CHF (seuil sous lequel 5 % de l'avoir n'atteignent plus la mise minimale de 2 CHF) et qu'aucun pari n'est en cours.

- Page : https://valejaqu1.github.io/kairos/
- Spécification : `docs/superpowers/specs/2026-10-12-kairos-design.md`
- Mise en route : `docs/SETUP.md`

Simulation uniquement : aucun argent réel, aucun compte de paris. Les cotes viennent de The Odds API, les résultats historiques de football-data.co.uk, le modèle de penaltyblog (MIT) ; la méthode d'analyste est adaptée de sports-betting-claude (MIT).
