# Kairos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire Kairos, un agent parieur en simulation qui vit d'une cagnotte fictive, apprend de ses prévisions et s'affiche sur une page publique avec un message Telegram quotidien.

**Architecture:** Un paquet Python déterministe (`kairos/`) fait tout ce qui touche à l'argent, aux clés et aux règles, lancé par trois workflows GitHub Actions (prepare, apply, closing). Une routine Claude dans le cloud, sans clé ni connecteur, lit les fichiers du dépôt, cherche l'actu sur le web et écrit un seul fichier de décisions par jour. La page est un site statique (GitHub Pages) qui lit `site/data.json`.

**Tech Stack:** Python 3.12, penaltyblog 1.13 (Dixon-Coles, probabilités sans marge), pandas, requests, pytest, PyYAML (tests), GitHub Actions, GitHub Pages, The Odds API v4, football-data.co.uk, API Bot Telegram, routines Claude Code.

**Spec:** `docs/superpowers/specs/2026-10-12-kairos-design.md`

## Global Constraints

- Simulation uniquement : aucun appel à un site de paris, aucun argent réel, aucune lecture de jeux.loro.ch.
- Montants en centimes entiers dans tout le code ; affichage « 104,20 ».
- Cagnotte de départ 10 000 centimes ; faim 25 centimes par jour calendaire (Europe/Zurich), jours manqués rattrapés.
- Cote simulée = cote médiane UE × 0,95, arrondie à 2 décimales, plancher 1,01.
- Seuil de valeur : p × cote simulée − 1 ≥ 0,05.
- Mise : ¼ de Kelly, plafond 5 % de l'avoir (cagnotte + mises en cours), arrondi vers le bas à 10 centimes, minimum 200 centimes sinon pas de pari (minimum d'un pari Single en ligne chez Jouez Sport, règlement 17e éd., art. 9).
- Cote d'un pari ≥ 1,10 (règlement Jouez Sport, art. 7) ; en dessous, pas de pari.
- 3 paris par jour au maximum ; mises en cours ≤ 15 % de l'avoir.
- Mort : cagnotte < 200 centimes (impossible de miser le minimum) et aucun pari ouvert. Diplôme évalué une fois au jour 56.
- Pari non réglé 3 jours après le coup d'envoi : remboursé (statut `void`).
- Fenêtre d'analyse : matchs des 48 h suivantes ; 10 prévisions par jour au maximum ; message ≤ 600 caractères ; 15 leçons au maximum ; 1 nouvelle source par jour au maximum ; statut de source tranché à 10 utilisations.
- Sous 50 crédits The Odds API restants : sauter d'abord les captures de clôture, puis les championnats sans pari ouvert.
- Championnats : `soccer_epl`, `soccer_spain_la_liga`, `soccer_italy_serie_a`, `soccer_germany_bundesliga` par défaut, tous vus dans l'offre Jouez Sport le 2026-10-12. La Super League suisse (`soccer_switzerland_superleague`, fichier football-data `new/SWZ.csv`, format « new » déjà géré) est à ajouter si Jouez Sport la propose un jour de championnat. La liste définitive est l'intersection de l'offre football réelle de Jouez Sport (relevée par l'utilisateur), des championnats de The Odds API et de football-data.co.uk ; elle est fixée à la tâche 16.
- Marché : 1X2 temps réglementaire uniquement (pari « 1X2 classique », annexe 1 du règlement Jouez Sport, art. 1).
- Déclencheurs de workflows : `schedule`, `push` sur `main`, `workflow_dispatch` uniquement. Jamais `pull_request_target`.
- Tout texte écrit par l'IA est affiché sur la page avec `textContent`, jamais `innerHTML`.
- Les clés ne vivent que dans les secrets GitHub Actions (`ODDS_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`). La routine Claude n'en a aucune.
- Commits : messages en français, terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

`kairos/store.py` :

```python
import json
import os
import tempfile
from datetime import date, datetime, timezone
from pathlib import Path
from zoneinfo import ZoneInfo

from kairos.config import START_BANKROLL_CENTS, root


def _path(rel: str) -> Path:
    return root() / rel


def read_json(rel: str, default):
    p = _path(rel)
    if not p.exists():
        return default
    return json.loads(p.read_text(encoding="utf-8"))


def write_json(rel: str, data) -> None:
    p = _path(rel)
    p.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=p.parent, suffix=".tmp")
    with os.fdopen(fd, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2, sort_keys=True)
        f.write("\n")
    os.replace(tmp, p)


def read_text(rel: str, default: str) -> str:
    p = _path(rel)
    return p.read_text(encoding="utf-8") if p.exists() else default


def write_text(rel: str, text: str) -> None:
    p = _path(rel)
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(text, encoding="utf-8")


def new_state(today: date) -> dict:
    return {
        "name": "Kairos",
        "generation": 1,
        "start_date": today.isoformat(),
        "bankroll_cents": START_BANKROLL_CENTS,
        "hunger_paid_through": today.isoformat(),
        "hunger_total_cents": 0,
        "alive": True,
        "death_date": None,
        "death_announced": False,
        "diploma": None,
        "diploma_announced": False,
        "trophies": {},
        "applied_decisions": [],
        "silent_notified": None,
        "last_message": None,
        "last_message_date": None,
        "last_run": None,
        "history": [],
    }


def load_state(today: date) -> dict:
    return read_json("state/kairos.json", None) or new_state(today)


def save_state(state: dict) -> None:
    write_json("state/kairos.json", state)


def load_bets() -> list:
    return read_json("state/bets.json", [])


def save_bets(bets: list) -> None:
    write_json("state/bets.json", bets)


def load_forecasts() -> list:
    return read_json("state/forecasts.json", [])


def save_forecasts(forecasts: list) -> None:
    write_json("state/forecasts.json", forecasts)


def load_sources() -> dict:
    return read_json("memory/sources.json", {})


def save_sources(sources: dict) -> None:
    write_json("memory/sources.json", sources)


def utcnow() -> datetime:
    return datetime.now(timezone.utc)


def parse_ts(value: str) -> datetime:
    return datetime.fromisoformat(value.replace("Z", "+00:00"))


def zurich_today(now: datetime | None = None) -> date:
    return (now or utcnow()).astimezone(ZoneInfo("Europe/Zurich")).date()


def day_number(state: dict, today: date) -> int:
    return (today - date.fromisoformat(state["start_date"])).days + 1


def append_journal(today: date, title: str, lines: list[str]) -> None:
    rel = f"journal/{today.isoformat()}.md"
    text = read_text(rel, f"# Journal de Kairos · {today.isoformat()}\n")
    body = "\n".join(f"- {line}" for line in lines) if lines else "- rien à signaler"
    write_text(rel, f"{text}\n## {title}\n\n{body}\n")
```

```python
import re
import unicodedata
from difflib import get_close_matches

from kairos.store import read_json

COMMON_TOKENS = {"fc", "afc", "cf", "ac", "as", "sc", "ssc", "fk", "bc", "bsc", "club", "calcio", "1", "sv", "tsg", "vfb", "vfl", "us"}


def normalize(name: str) -> str:
    s = unicodedata.normalize("NFKD", name).encode("ascii", "ignore").decode().lower()
    s = re.sub(r"[^a-z0-9 ]", " ", s)
    return " ".join(t for t in s.split() if t not in COMMON_TOKENS)


def match_team(name: str, candidates: list[str], aliases: dict[str, str]) -> str | None:
    if name in aliases and aliases[name] in candidates:
        return aliases[name]
    by_norm = {normalize(c): c for c in candidates}
    n = normalize(name)
    if not n:
        return None
    if n in by_norm:
        return by_norm[n]
    for key, cand in by_norm.items():
        if min(len(n), len(key)) >= 4 and (n.startswith(key) or key.startswith(n)):
            return cand
    close = get_close_matches(n, list(by_norm), n=1, cutoff=0.8)
    return by_norm[close[0]] if close else None


def load_aliases() -> dict[str, str]:
    return read_json("data/team_aliases.json", {})
```

Note : avec l'alias absent, « Brighton and Hove Albion » se normalise en « brighton and hove albion », qui commence par « brighton » (clé normalisée de « Brighton ») : la règle de préfixe le trouve.

```python
from datetime import datetime, timedelta
from statistics import median

from kairos.config import LOOKAHEAD_HOURS, MIN_SIM_ODDS, ODDS_HAIRCUT
from kairos.store import parse_ts

SELECTIONS = ("1", "X", "2")
SEL_INDEX = {"1": 0, "X": 1, "2": 2}


def event_prices(event: dict) -> dict[str, list[float]]:
    prices: dict[str, list[float]] = {"1": [], "X": [], "2": []}
    for book in event.get("bookmakers", []):
        for market in book.get("markets", []):
            if market.get("key") != "h2h":
                continue
            for outcome in market.get("outcomes", []):
                price = float(outcome["price"])
                if outcome["name"] == event["home_team"]:
                    prices["1"].append(price)
                elif outcome["name"] == event["away_team"]:
                    prices["2"].append(price)
                elif outcome["name"] == "Draw":
                    prices["X"].append(price)
    return prices


def simulated(odds: float) -> float:
    return max(MIN_SIM_ODDS, round(odds * ODDS_HAIRCUT, 2))


def summarize_event(event: dict, sport_key: str) -> dict | None:
    prices = event_prices(event)
    if any(not prices[s] for s in SELECTIONS):
        return None
    med = {s: round(median(prices[s]), 3) for s in SELECTIONS}
    return {
        "event_id": event["id"],
        "sport_key": sport_key,
        "home": event["home_team"],
        "away": event["away_team"],
        "commence_time": event["commence_time"],
        "median": med,
        "sim": {s: simulated(med[s]) for s in SELECTIONS},
        "n_books": min(len(prices[s]) for s in SELECTIONS),
    }


def within_lookahead(summaries: list[dict], now: datetime) -> list[dict]:
    end = now + timedelta(hours=LOOKAHEAD_HOURS)
    return [s for s in summaries if now < parse_ts(s["commence_time"]) <= end]
```

```python
import json
import time
from pathlib import Path

import requests

BASE = "https://api.the-odds-api.com/v4"
RETRY_STATUSES = {429, 500, 502, 503, 504}


class OddsApi:
    def __init__(self, key: str, session=None):
        self.key = key
        self.session = session or requests.Session()
        self.remaining: int | None = None

    def _get(self, path: str, **params):
        params["apiKey"] = self.key
        last_error: Exception | None = None
        for attempt in range(3):
            try:
                resp = self.session.get(f"{BASE}{path}", params=params, timeout=30)
            except requests.ConnectionError as exc:
                last_error = exc
            else:
                if resp.status_code not in RETRY_STATUSES:
                    resp.raise_for_status()
                    remaining = resp.headers.get("x-requests-remaining")
                    if remaining is not None:
                        self.remaining = int(float(remaining))
                    return resp.json()
                last_error = RuntimeError(f"HTTP {resp.status_code}")
            if attempt < 2:
                time.sleep(5 * (attempt + 1))
        raise last_error

    def odds(self, sport_key: str) -> list:
        return self._get(f"/sports/{sport_key}/odds/", regions="eu", markets="h2h", oddsFormat="decimal", dateFormat="iso")

    def scores(self, sport_key: str) -> list:
        return self._get(f"/sports/{sport_key}/scores/", daysFrom=3, dateFormat="iso")

    def event_odds(self, sport_key: str, event_id: str) -> dict:
        return self._get(f"/sports/{sport_key}/events/{event_id}/odds", regions="eu", markets="h2h", oddsFormat="decimal", dateFormat="iso")

    def sports(self) -> list:
        return self._get("/sports/")


class FakeOddsApi:
    def __init__(self, fixtures: Path, remaining: int = 500):
        self.dir = Path(fixtures)
        self.remaining = remaining

    def _load(self, name: str, default):
        p = self.dir / name
        return json.loads(p.read_text(encoding="utf-8")) if p.exists() else default

    def odds(self, sport_key: str) -> list:
        return self._load(f"odds_{sport_key}.json", [])

    def scores(self, sport_key: str) -> list:
        return self._load(f"scores_{sport_key}.json", [])

    def event_odds(self, sport_key: str, event_id: str) -> dict:
        return self._load(f"event_odds_{event_id}.json", {})

    def sports(self) -> list:
        return self._load("sports.json", [])
```

```python
import io
from datetime import date, timedelta

import pandas as pd
import penaltyblog as pb
import requests

from kairos.config import HISTORY_DAYS, League
from kairos.teams import match_team

COLUMNS = {
    "main": {"HomeTeam": "home", "AwayTeam": "away", "FTHG": "hg", "FTAG": "ag"},
    "new": {"Home": "home", "Away": "away", "HG": "hg", "AG": "ag"},
}


def season_codes(today: date) -> list[str]:
    start = today.year if today.month >= 7 else today.year - 1
    return [f"{(start - 1) % 100:02d}{start % 100:02d}", f"{start % 100:02d}{(start + 1) % 100:02d}"]


def parse_results(csv_text: str, fmt: str) -> pd.DataFrame:
    df = pd.read_csv(io.StringIO(csv_text)).rename(columns=COLUMNS[fmt])
    df = df[["Date", "home", "away", "hg", "ag"]].dropna()
    df["date"] = pd.to_datetime(df["Date"], dayfirst=True, errors="coerce")
    df = df.dropna(subset=["date"])
    df["hg"] = df["hg"].astype(int)
    df["ag"] = df["ag"].astype(int)
    return df[["date", "home", "away", "hg", "ag"]].reset_index(drop=True)


def fetch_results(league: League, today: date, get=requests.get) -> pd.DataFrame:
    if league.fd_format == "new":
        urls = [league.fd_url]
    else:
        urls = [league.fd_url.format(season=code) for code in season_codes(today)]
    frames = []
    for url in urls:
        resp = get(url, timeout=60)
        if resp.status_code == 200 and resp.content.strip():
            frames.append(parse_results(resp.content.decode("utf-8-sig", errors="replace"), league.fd_format))
    if not frames:
        raise RuntimeError(f"aucun résultat pour {league.sport_key}")
    df = pd.concat(frames, ignore_index=True)
    cutoff = pd.Timestamp(today - timedelta(days=HISTORY_DAYS))
    return df[df["date"] >= cutoff].sort_values("date").reset_index(drop=True)


def fit_model(df: pd.DataFrame, today: date):
    weights = pb.models.dixon_coles_weights(df["date"], xi=0.0018, base_date=pd.Timestamp(today))
    model = pb.models.DixonColesGoalModel(df["hg"], df["ag"], df["home"], df["away"], weights)
    model.fit()
    return model


def predict_events(model, teams: list[str], events: list[dict], aliases: dict) -> tuple[dict, list[str]]:
    preds: dict[str, list[float] | None] = {}
    unmatched: set[str] = set()
    for ev in events:
        home = match_team(ev["home"], teams, aliases)
        away = match_team(ev["away"], teams, aliases)
        if home is None:
            unmatched.add(ev["home"])
        if away is None:
            unmatched.add(ev["away"])
        if home is None or away is None or home == away:
            preds[ev["event_id"]] = None
            continue
        grid = model.predict(home, away)
        preds[ev["event_id"]] = [round(float(grid.home_win), 4), round(float(grid.draw), 4), round(float(grid.away_win), 4)]
    return preds, sorted(unmatched)
```

```python
def rps(p: list[float], outcome: int) -> float:
    observed = [0.0, 0.0, 0.0]
    observed[outcome] = 1.0
    cum_p = cum_o = total = 0.0
    for k in range(2):
        cum_p += p[k]
        cum_o += observed[k]
        total += (cum_p - cum_o) ** 2
    return round(total / 2, 6)


def clv(taken: float, closing: float) -> float:
    return round(taken / closing - 1, 4)


def outcome_from_goals(home: int, away: int) -> int:
    if home > away:
        return 0
    if home == away:
        return 1
    return 2
```

```python
from kairos.config import DEATH_THRESHOLD_CENTS, HUNGER_CENTS_PER_DAY


def apply_hunger(state: dict, today: date) -> int:
    days = (today - date.fromisoformat(state["hunger_paid_through"])).days
    if days <= 0 or not state["alive"]:
        return 0
    cost = min(days * HUNGER_CENTS_PER_DAY, max(state["bankroll_cents"], 0))
    state["bankroll_cents"] -= cost
    state["hunger_total_cents"] = state.get("hunger_total_cents", 0) + cost
    state["hunger_paid_through"] = today.isoformat()
    return cost


def check_death(state: dict, bets: list, today: date) -> bool:
    if not state["alive"]:
        return False
    has_open = any(b["status"] == "open" for b in bets)
    if state["bankroll_cents"] < DEATH_THRESHOLD_CENTS and not has_open:
        state["alive"] = False
        state["death_date"] = today.isoformat()
        return True
    return False
```

```python
from datetime import date, datetime, timedelta

from kairos.config import VOID_AFTER_DAYS
from kairos.odds import SEL_INDEX
from kairos.scoring import outcome_from_goals, rps
from kairos.store import parse_ts


def parse_scores(payload: list) -> dict[str, int]:
    outcomes: dict[str, int] = {}
    for game in payload:
        if not game.get("completed") or not game.get("scores"):
            continue
        goals = {s["name"]: int(s["score"]) for s in game["scores"]}
        if game["home_team"] in goals and game["away_team"] in goals:
            outcomes[game["id"]] = outcome_from_goals(goals[game["home_team"]], goals[game["away_team"]])
    return outcomes


def _stale(item: dict, now: datetime) -> bool:
    return parse_ts(item["commence_time"]) + timedelta(days=VOID_AFTER_DAYS) < now


def settle_bets(state: dict, bets: list, outcomes: dict[str, int], now: datetime, today: date) -> list[dict]:
    settled = []
    for b in bets:
        if b["status"] != "open":
            continue
        if b["event_id"] in outcomes:
            won = outcomes[b["event_id"]] == SEL_INDEX[b["selection"]]
            b["status"] = "won" if won else "lost"
            b["payout_cents"] = round(b["stake_cents"] * b["odds_sim"]) if won else 0
        elif _stale(b, now):
            b["status"] = "void"
            b["payout_cents"] = b["stake_cents"]
        else:
            continue
        b["settled_date"] = today.isoformat()
        state["bankroll_cents"] += b["payout_cents"]
        settled.append(b)
    return settled


def score_forecasts(forecasts: list, outcomes: dict[str, int], now: datetime) -> int:
    scored = 0
    for f in forecasts:
        if f.get("outcome") is not None or f.get("void"):
            continue
        if f["event_id"] in outcomes:
            o = outcomes[f["event_id"]]
            f["outcome"] = o
            f["rps_kairos"] = rps(f["p_kairos"], o)
            f["rps_market"] = rps(f["p_market"], o)
            f["rps_model"] = rps(f["p_model"], o) if f.get("p_model") else None
            scored += 1
        elif _stale(f, now):
            f["void"] = True
    return scored


def sports_to_check(bets: list, forecasts: list, now: datetime) -> set[str]:
    pending = [b for b in bets if b["status"] == "open"]
    pending += [f for f in forecasts if f.get("outcome") is None and not f.get("void")]
    return {item["sport_key"] for item in pending if parse_ts(item["commence_time"]) < now}
```

```python
from datetime import date, datetime, timedelta

from kairos.config import (KELLY_FRACTION, KICKOFF_MARGIN_MIN, MAX_BETS_PER_DAY, MAX_EXPOSURE_SHARE, MAX_FORECASTS_PER_DAY,
                           MAX_LESSONS, MAX_LESSONS_ADDED, MAX_MESSAGE_CHARS, MAX_STAKE_SHARE, MIN_BET_ODDS, MIN_STAKE_CENTS,
                           STAKE_STEP_CENTS, VALUE_THRESHOLD)
from kairos.odds import SEL_INDEX
from kairos.store import parse_ts

LESSONS_HEADER = "# Leçons de Kairos\n\n"


def validate_decisions(dec: dict, today: date) -> list[str]:
    errors = []
    if not isinstance(dec, dict):
        return ["le fichier n'est pas un objet JSON"]
    if dec.get("date") != today.isoformat():
        errors.append("date incorrecte")
    if not isinstance(dec.get("forecasts"), list):
        errors.append("forecasts doit être une liste")
    if not isinstance(dec.get("bets"), list):
        errors.append("bets doit être une liste")
    message = dec.get("message")
    if not isinstance(message, str) or not message.strip():
        errors.append("message manquant")
    elif len(message) > MAX_MESSAGE_CHARS:
        errors.append("message trop long")
    return errors


def register_sources(dec: dict, sources: dict, today: date) -> str | None:
    new = dec.get("new_source")
    if not isinstance(new, dict) or not isinstance(new.get("id"), str) or not new["id"].strip():
        return None
    sid = new["id"].strip()
    if sid in sources:
        return None
    sources[sid] = {"description": str(new.get("description", ""))[:200], "url": str(new.get("url", ""))[:300],
                    "status": "test", "uses": 0, "score": None, "first_seen": today.isoformat()}
    return sid


def accept_forecasts(dec: dict, events: dict, model: dict, sources: dict, today: date):
    accepted, rejected = [], []
    for f in dec["forecasts"][:MAX_FORECASTS_PER_DAY]:
        eid = str(f.get("event_id"))
        ev = events.get(eid)
        if ev is None:
            rejected.append((eid, "match inconnu"))
            continue
        p = f.get("p")
        if not (isinstance(p, list) and len(p) == 3 and all(isinstance(x, (int, float)) and 0 <= x <= 1 for x in p)):
            rejected.append((eid, "probabilités invalides"))
            continue
        total = sum(p)
        if not 0.98 <= total <= 1.02:
            rejected.append((eid, "les probabilités ne somment pas à 1"))
            continue
        srcs = [s for s in f.get("sources", []) if isinstance(s, str) and s in sources and sources[s].get("status") != "dropped"]
        accepted.append({
            "date": today.isoformat(), "event_id": eid, "sport_key": ev["sport_key"], "home": ev["home"], "away": ev["away"],
            "commence_time": ev["commence_time"], "p_kairos": [round(x / total, 4) for x in p], "p_market": ev["p_market"],
            "p_model": model.get(eid), "sources": srcs, "note": str(f.get("note", ""))[:300],
            "outcome": None, "rps_kairos": None, "rps_market": None, "rps_model": None, "void": False,
        })
    return accepted, rejected


def stake_cents(p: float, odds: float, equity_cents: int) -> int:
    edge = p * odds - 1
    if odds <= 1 or edge < VALUE_THRESHOLD:
        return 0
    share = min(edge / (odds - 1) * KELLY_FRACTION, MAX_STAKE_SHARE)
    stake = int(share * equity_cents // STAKE_STEP_CENTS) * STAKE_STEP_CENTS
    return stake if stake >= MIN_STAKE_CENTS else 0


def place_bets(dec: dict, forecasts_by_event: dict, events: dict, state: dict, bets: list, now: datetime, today: date):
    placed, rejected = [], []
    open_stakes = sum(b["stake_cents"] for b in bets if b["status"] == "open")
    placed_today = sum(1 for b in bets if b["date"] == today.isoformat())
    for prop in dec["bets"]:
        eid, sel = str(prop.get("event_id")), prop.get("selection")
        if placed_today + len(placed) >= MAX_BETS_PER_DAY:
            rejected.append((eid, f"déjà {MAX_BETS_PER_DAY} paris aujourd'hui"))
            continue
        if sel not in SEL_INDEX:
            rejected.append((eid, "issue invalide"))
            continue
        forecast, ev = forecasts_by_event.get(eid), events.get(eid)
        if forecast is None or ev is None:
            rejected.append((eid, "pas de prévision acceptée pour ce match"))
            continue
        if any(b["event_id"] == eid and b["status"] == "open" for b in bets + placed):
            rejected.append((eid, "déjà un pari sur ce match"))
            continue
        if parse_ts(ev["commence_time"]) <= now + timedelta(minutes=KICKOFF_MARGIN_MIN):
            rejected.append((eid, "match trop proche ou déjà commencé"))
            continue
        odds, p = ev["sim"][sel], forecast["p_kairos"][SEL_INDEX[sel]]
        if odds < MIN_BET_ODDS:
            rejected.append((eid, "cote inférieure à 1,10"))
            continue
        equity = state["bankroll_cents"] + open_stakes
        stake = stake_cents(p, odds, equity)
        if stake == 0:
            edge = p * odds - 1
            rejected.append((eid, f"valeur insuffisante ({edge:+.1%})" if edge < VALUE_THRESHOLD else "mise inférieure à 2 CHF"))
            continue
        if open_stakes + stake > MAX_EXPOSURE_SHARE * equity:
            rejected.append((eid, "exposition maximale atteinte"))
            continue
        if stake > state["bankroll_cents"]:
            rejected.append((eid, "cagnotte insuffisante"))
            continue
        state["bankroll_cents"] -= stake
        open_stakes += stake
        placed.append({
            "id": f"{today.isoformat()}-{eid}-{sel}", "date": today.isoformat(), "event_id": eid, "sport_key": ev["sport_key"],
            "home": ev["home"], "away": ev["away"], "commence_time": ev["commence_time"], "selection": sel,
            "odds_median": ev["median"][sel], "odds_sim": odds, "stake_cents": stake, "p_kairos": p,
            "p_market": ev["p_market"][SEL_INDEX[sel]], "status": "open", "payout_cents": None, "closing_odds": None,
            "settled_date": None, "reasoning": str(prop.get("reasoning", ""))[:400],
        })
    bets.extend(placed)
    return placed, rejected


def update_lessons(text: str, changes: dict | None, today: date) -> tuple[str, list[str]]:
    if not changes:
        return text, []
    if today.weekday() != 6:
        return text, ["leçons ignorées : on ne les modifie que le dimanche"]
    lines = [l[2:].strip() for l in text.splitlines() if l.startswith("- ")]
    notes = []
    for item in changes.get("remove", []) or []:
        if item in lines:
            lines.remove(item)
    adds = [str(a).strip()[:200] for a in (changes.get("add", []) or []) if str(a).strip()]
    if len(adds) > MAX_LESSONS_ADDED:
        notes.append(f"{len(adds) - MAX_LESSONS_ADDED} ajout ignoré ({MAX_LESSONS_ADDED} au maximum)")
        adds = adds[:MAX_LESSONS_ADDED]
    for a in adds:
        if len(lines) >= MAX_LESSONS:
            notes.append(f"ajout ignoré : déjà {MAX_LESSONS} leçons")
            break
        lines.append(a)
    return LESSONS_HEADER + "".join(f"- {l}\n" for l in lines), notes
```

```python
from datetime import date

from kairos.config import DIPLOMA_CLV_SHARE, DIPLOMA_DAY, SOURCE_MIN_USES, START_BANKROLL_CENTS
from kairos.scoring import clv
from kairos.store import day_number

TIERS = (("Bronze", 0.0, 0.45), ("Argent", 0.45, 0.55), ("Or", 0.55, 0.62))
DIVISIONS = ("I", "II", "III")
TROPHIES = {
    "premier_gain": "Premier pari gagné",
    "serie_3": "Série de 3",
    "serie_5": "Série de 5",
    "source_gardee": "Première source validée",
    "clv_10": "10 paris avant le marché",
    "survie_4_semaines": "4 semaines de survie",
    "diplome": "Diplômé",
}


def settled_forecasts(forecasts: list) -> list:
    return [f for f in forecasts if f.get("outcome") is not None]


def skill(f: dict) -> float:
    return f["rps_market"] - f["rps_kairos"]


def bet_clv(b: dict) -> float | None:
    return clv(b["odds_median"], b["closing_odds"]) if b.get("closing_odds") else None


def equity_cents(state: dict, bets: list) -> int:
    return state["bankroll_cents"] + sum(b["stake_cents"] for b in bets if b["status"] == "open")


def update_sources(sources: dict, forecasts: list) -> None:
    per_source: dict[str, list[float]] = {}
    for f in settled_forecasts(forecasts):
        for sid in f.get("sources", []):
            per_source.setdefault(sid, []).append(skill(f))
    for sid, meta in sources.items():
        values = per_source.get(sid, [])
        meta["uses"] = len(values)
        meta["score"] = round(sum(values) / len(values), 4) if values else None
        if len(values) >= SOURCE_MIN_USES:
            meta["status"] = "kept" if meta["score"] > 0 else "dropped"
        else:
            meta["status"] = "test"


def _settled_bets(bets: list) -> list:
    done = [b for b in bets if b["status"] in ("won", "lost")]
    return sorted(done, key=lambda b: (b["settled_date"], b["commence_time"]))


def rank(forecasts: list, bets: list) -> dict:
    recent_fc = settled_forecasts(forecasts)[-30:]
    recent_clv = [c for c in (bet_clv(b) for b in _settled_bets(bets)) if c is not None][-20:]
    parts = []
    if recent_fc:
        parts.append(sum(1 for f in recent_fc if skill(f) > 0) / len(recent_fc))
    if recent_clv:
        parts.append(sum(1 for c in recent_clv if c > 0) / len(recent_clv))
    score = sum(parts) / len(parts) if parts else 0.0
    if score >= 0.62:
        return {"tier": "Platine", "division": None, "score": round(score, 3), "progress": 1.0, "next": None}
    for i, (name, lo, hi) in enumerate(TIERS):
        if score < hi:
            third = (hi - lo) / 3
            idx = min(2, int((score - lo) // third))
            progress = (score - (lo + idx * third)) / third
            if idx < 2:
                nxt = f"{name} {DIVISIONS[idx + 1]}"
            else:
                nxt = "Platine" if i == len(TIERS) - 1 else f"{TIERS[i + 1][0]} I"
            return {"tier": name, "division": DIVISIONS[idx], "score": round(score, 3), "progress": round(progress, 3), "next": nxt}
    raise AssertionError("unreachable")


def current_streak(bets: list) -> int:
    streak = 0
    for b in reversed(_settled_bets(bets)):
        if b["status"] != "won":
            break
        streak += 1
    return streak


def _best_streak(bets: list) -> int:
    best = run = 0
    for b in _settled_bets(bets):
        run = run + 1 if b["status"] == "won" else 0
        best = max(best, run)
    return best


def update_trophies(state: dict, bets: list, sources: dict, today: date) -> list[str]:
    earned = state["trophies"]
    new = []

    def award(key: str) -> None:
        if key not in earned:
            earned[key] = today.isoformat()
            new.append(key)

    if any(b["status"] == "won" for b in bets):
        award("premier_gain")
    best = _best_streak(bets)
    if best >= 3:
        award("serie_3")
    if best >= 5:
        award("serie_5")
    if any(m.get("status") == "kept" for m in sources.values()):
        award("source_gardee")
    if sum(1 for b in bets if (c := bet_clv(b)) is not None and c > 0) >= 10:
        award("clv_10")
    if state["alive"] and day_number(state, today) >= 28:
        award("survie_4_semaines")
    if state.get("diploma") == "obtenu":
        award("diplome")
    return new


def check_diploma(state: dict, bets: list, forecasts: list, today: date) -> str | None:
    if state.get("diploma") is not None or day_number(state, today) < DIPLOMA_DAY:
        return None
    scored = settled_forecasts(forecasts)
    mean_skill = sum(skill(f) for f in scored) / len(scored) if scored else 0.0
    clvs = [c for c in (bet_clv(b) for b in bets) if c is not None]
    clv_share = sum(1 for c in clvs if c > 0) / len(clvs) if clvs else 0.0
    ok = state["alive"] and equity_cents(state, bets) >= START_BANKROLL_CENTS and mean_skill > 0 and clv_share >= DIPLOMA_CLV_SHARE
    state["diploma"] = "obtenu" if ok else "manqué"
    return state["diploma"]


def stats(bets: list) -> dict:
    done = _settled_bets(bets)
    staked = sum(b["stake_cents"] for b in done)
    returned = sum(b["payout_cents"] for b in done)
    clvs = [c for c in (bet_clv(b) for b in done) if c is not None]
    return {
        "bets": len(done),
        "won": sum(1 for b in done if b["status"] == "won"),
        "roi": (returned - staked) / staked if staked else 0.0,
        "clv_avg": sum(clvs) / len(clvs) if clvs else 0.0,
        "clv_beats": sum(1 for c in clvs if c > 0),
        "clv_total": len(clvs),
    }
```

```python
from datetime import datetime, timedelta
from statistics import median

from kairos.config import CLOSING_WINDOW_MIN, CREDIT_FLOOR
from kairos.odds import event_prices
from kairos.store import parse_ts


def due_bets(bets: list, now: datetime) -> list[dict]:
    end = now + timedelta(minutes=CLOSING_WINDOW_MIN)
    return [b for b in bets if b["status"] == "open" and b.get("closing_odds") is None and now <= parse_ts(b["commence_time"]) <= end]


def capture(api, bets: list, now: datetime) -> int:
    captured = 0
    for b in due_bets(bets, now):
        if api.remaining is not None and api.remaining < CREDIT_FLOOR:
            break
        event = api.event_odds(b["sport_key"], b["event_id"])
        if not event:
            continue
        prices = event_prices(event)[b["selection"]]
        if prices:
            b["closing_odds"] = round(median(prices), 3)
            captured += 1
    return captured
```

```python
    if not state["alive"]:
        return 0.0
    return max(0.0, min(1.0, equity / (START_BANKROLL_CENTS * 1.2)))


def mood(state: dict, bets: list, equity: int) -> str:
    if not state["alive"]:
        return "Éteint"
    if state.get("diploma") == "obtenu":
        return "Diplômé"
```

```python
import requests

from kairos.metrics import equity_cents


def chf(cents: int) -> str:
    sign = "−" if cents < 0 else ""
    return f"{sign}{abs(cents) / 100:.2f}".replace(".", ",")


def compose_daily(state: dict, bets: list, placed: list, hunger_cents: int, page_url: str) -> str:
    n = len(placed)
    line = f"Avoir {chf(equity_cents(state, bets))} CHF · faim −{chf(hunger_cents)} · {n} pari{'s' if n > 1 else ''} placé{'s' if n > 1 else ''}"
    message = state.get("last_message") or "Kairos n'a pas donné signe de vie aujourd'hui."
    return f"{message}\n\n{line}\n{page_url}"


def compose_death(state: dict, page_url: str) -> str:
    return (f"Kairos est mort le {state['death_date']}. Cagnotte finale : {chf(state['bankroll_cents'])} CHF.\n"
            f"Son histoire reste en ligne : {page_url}")


def compose_diploma(state: dict, result: str, page_url: str) -> str:
    if result == "obtenu":
        return f"Jour 56 : Kairos décroche son diplôme. Il a battu le marché et survécu.\n{page_url}"
    return f"Jour 56 : pas de diplôme pour Kairos. La simulation continue jusqu'à la fin.\n{page_url}"


def send(token: str, chat_id: str, text: str, post=requests.post) -> None:
    resp = post(f"https://api.telegram.org/bot{token}/sendMessage",
                json={"chat_id": chat_id, "text": text, "disable_web_page_preview": True}, timeout=30)
    resp.raise_for_status()
```

```python
import argparse
import json
import os
import sys
from dataclasses import dataclass
from datetime import date, datetime
from pathlib import Path
from typing import Callable

from kairos import store
from kairos.config import CREDIT_FLOOR, DEFAULT_PAGE_URL, LEAGUES


@dataclass
class Context:
    api: object
    http_get: Callable
    notify: Callable[[str], None]
    today: date
    now: datetime
    page_url: str


def cmd_prepare(ctx: Context) -> None:
    from kairos.hunger import apply_hunger, check_death
    from kairos.market import no_vig
    from kairos.model import fetch_results, fit_model, predict_events
    from kairos.odds import summarize_event, within_lookahead
    from kairos.settle import parse_scores, score_forecasts, settle_bets, sports_to_check
    from kairos.teams import load_aliases

    state, bets, forecasts = store.load_state(ctx.today), store.load_bets(), store.load_forecasts()
    notes = []
    if not state["alive"]:
        store.save_state(state)
        return
    outcomes = {}
    for key in sorted(sports_to_check(bets, forecasts, ctx.now)):
        try:
            outcomes.update(parse_scores(ctx.api.scores(key)))
        except Exception as exc:
            notes.append(f"résultats indisponibles pour {key} : {exc}")
    settled = settle_bets(state, bets, outcomes, ctx.now, ctx.today)
    scored = score_forecasts(forecasts, outcomes, ctx.now)
    hunger = apply_hunger(state, ctx.today)
    notes.append(f"{len(settled)} pari(s) réglé(s), {scored} prévision(s) notée(s), faim −{hunger / 100:.2f} CHF")

    open_keys = {b["sport_key"] for b in bets if b["status"] == "open"}
    events = []
    for league in LEAGUES:
        if ctx.api.remaining is not None and ctx.api.remaining < CREDIT_FLOOR and league.sport_key not in open_keys:
            notes.append(f"{league.label} sauté : crédits bas ({ctx.api.remaining})")
            continue
        try:
            raw = ctx.api.odds(league.sport_key)
        except Exception as exc:
            notes.append(f"cotes indisponibles pour {league.label} : {exc}")
            continue
        summaries = [s for s in (summarize_event(e, league.sport_key) for e in raw) if s]
        for s in within_lookahead(summaries, ctx.now):
            s["p_market"] = no_vig(s["median"])
            events.append(s)
    store.write_json(f"data/odds/{ctx.today.isoformat()}.json", {"fetched_at": ctx.now.isoformat(), "events": events})

    preds, unmatched = {}, []
    aliases = load_aliases()
    for league in LEAGUES:
        league_events = [e for e in events if e["sport_key"] == league.sport_key]
        if not league_events:
            continue
        try:
            df = fetch_results(league, ctx.today, get=ctx.http_get)
            model = fit_model(df, ctx.today)
            teams = sorted(set(df["home"]) | set(df["away"]))
            p, um = predict_events(model, teams, league_events, aliases)
            preds.update(p)
            unmatched += um
        except Exception as exc:
            notes.append(f"modèle indisponible pour {league.label} : {exc}")
            preds.update({e["event_id"]: None for e in league_events})
    store.write_json(f"data/model/{ctx.today.isoformat()}.json", {"events": preds, "unmatched": sorted(set(unmatched))})
    notes.append(f"{len(events)} match(s) dans les 48 h, {len(set(unmatched))} équipe(s) non reconnue(s)")

    check_death(state, bets, ctx.today)
    state["last_run"] = ctx.now.isoformat()
    store.save_state(state)
    store.save_bets(bets)
    store.save_forecasts(forecasts)
    store.append_journal(ctx.today, "Matin", notes)


def cmd_apply(ctx: Context) -> None:
    from kairos.hunger import check_death
    from kairos.metrics import check_diploma, equity_cents, update_sources, update_trophies
    from kairos.notify import compose_daily, compose_death, compose_diploma
    from kairos.rules import LESSONS_HEADER, accept_forecasts, place_bets, register_sources, update_lessons, validate_decisions
    from kairos.site import build_site_data, write_site

    today = ctx.today.isoformat()
    state, bets, forecasts, sources = store.load_state(ctx.today), store.load_bets(), store.load_forecasts(), store.load_sources()
    lessons = store.read_text("memory/lessons.md", LESSONS_HEADER)
    messages, notes, placed = [], [], []

    if state["alive"] and today not in state["applied_decisions"]:
        events = {e["event_id"]: e for e in store.read_json(f"data/odds/{today}.json", {"events": []})["events"]}
        model = store.read_json(f"data/model/{today}.json", {"events": {}})["events"]
        dec = store.read_json(f"decisions/{today}.json", None)
        if dec is not None:
            errors = validate_decisions(dec, ctx.today)
            if errors:
                notes.append("décisions rejetées : " + "; ".join(errors))
                state["last_message"] = "J'ai rendu une copie illisible aujourd'hui. Aucun pari."
            else:
                new_source = register_sources(dec, sources, ctx.today)
                if new_source:
                    notes.append(f"nouvelle source en test : {new_source}")
                accepted, rejected = accept_forecasts(dec, events, model, sources, ctx.today)
                forecasts.extend(accepted)
                placed, rejected_bets = place_bets(dec, {f["event_id"]: f for f in accepted}, events, state, bets, ctx.now, ctx.today)
                lessons, lesson_notes = update_lessons(lessons, dec.get("lessons"), ctx.today)
                notes += [f"{len(accepted)} prévision(s), {len(placed)} pari(s) placé(s)"]
                notes += [f"prévision rejetée {eid} : {why}" for eid, why in rejected]
                notes += [f"pari rejeté {eid} : {why}" for eid, why in rejected_bets]
                notes += lesson_notes
                state["last_message"] = dec["message"].strip()
            state["last_message_date"] = today
            state["applied_decisions"].append(today)
            messages.append("daily")
        elif state.get("silent_notified") != today:
            state["last_message"] = None
            state["last_message_date"] = today
            state["silent_notified"] = today
            notes.append("pas de fichier de décisions")
            messages.append("daily")

    update_sources(sources, forecasts)
    update_trophies(state, bets, sources, ctx.today)
    diploma = check_diploma(state, bets, forecasts, ctx.today)
    check_death(state, bets, ctx.today)
    history = [h for h in state["history"] if h["date"] != today]
    state["history"] = history + [{"date": today, "equity_cents": equity_cents(state, bets)}]
    state["last_run"] = ctx.now.isoformat()

    store.save_state(state)
    store.save_bets(bets)
    store.save_forecasts(forecasts)
    store.save_sources(sources)
    store.write_text("memory/lessons.md", lessons)
    if notes:
        store.append_journal(ctx.today, "Décisions", notes)
    write_site(build_site_data(state, bets, forecasts, sources, lessons, ctx.today, ctx.now))

    hunger_today = 0
    if "daily" in messages and state["alive"]:
        journal = store.read_text(f"journal/{today}.md", "")
        for line in journal.splitlines():
            if "faim −" in line:
                hunger_today = round(float(line.split("faim −")[1].split(" ")[0]) * 100)
        ctx.notify(compose_daily(state, bets, placed, hunger_today, ctx.page_url))
    if diploma:
        ctx.notify(compose_diploma(state, diploma, ctx.page_url))
    if not state["alive"] and not state.get("death_announced"):
        ctx.notify(compose_death(state, ctx.page_url))
        state["death_announced"] = True
        store.save_state(state)


def cmd_closing(ctx: Context) -> None:
    from kairos.closing import capture

    bets = store.load_bets()
    if capture(ctx.api, bets, ctx.now):
        store.save_bets(bets)


def cmd_check_decisions(path: str, today: date) -> int:
    from kairos.rules import validate_decisions

    try:
        dec = json.loads(Path(path).read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as exc:
        print(f"illisible : {exc}")
        return 1
    errors = validate_decisions(dec, today)
    for e in errors:
        print(f"erreur : {e}")
    if not errors:
        print("fichier de décisions valide")
    return 1 if errors else 0


def cmd_check_api(api) -> str:
    keys = {league.sport_key for league in LEAGUES}
    found = {s["key"] for s in api.sports() if s.get("group") == "Soccer"}
    lines = [f"{'OK ' if k in found else 'ABSENT'} {k}" for k in sorted(keys)]
    api.odds("soccer_epl")
    lines.append(f"crédits restants : {api.remaining}")
    return "\n".join(lines)


def _real_context() -> Context:
    import requests

    from kairos.api import OddsApi
    from kairos.notify import send

    token, chat = os.environ.get("TELEGRAM_BOT_TOKEN"), os.environ.get("TELEGRAM_CHAT_ID")

    def notify(text: str) -> None:
        if token and chat:
            send(token, chat, text)
        else:
            print(text)

    now = store.utcnow()
    return Context(api=OddsApi(os.environ.get("ODDS_API_KEY", "")), http_get=requests.get, notify=notify,
                   today=store.zurich_today(now), now=now, page_url=os.environ.get("PAGE_URL", DEFAULT_PAGE_URL))


def main(argv=None) -> int:
    parser = argparse.ArgumentParser(prog="kairos")
    parser.add_argument("command", choices=["prepare", "apply", "closing", "check-decisions", "check-api"])
    parser.add_argument("path", nargs="?")
    args = parser.parse_args(argv)
    if args.command == "check-decisions":
        return cmd_check_decisions(args.path, store.zurich_today())
    ctx = _real_context()
    if args.command == "prepare":
        cmd_prepare(ctx)
    elif args.command == "apply":
        cmd_apply(ctx)
    elif args.command == "closing":
        cmd_closing(ctx)
    else:
        print(cmd_check_api(ctx.api))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```markdown
# Méthode d'analyste de Kairos

Méthode adaptée au football de sports-betting-claude (licence MIT, © 2024 Sports Betting Claude Contributors).

## 1. Le marché est ton point de départ

`p_market` est la probabilité implicite des bookmakers, marge retirée. Le marché a souvent raison : il agrège beaucoup d'information. Tu ne t'en écartes que pour une raison précise et vérifiable.

- Écart de moins de 3 points : normal, c'est du bruit.
- Écart de 3 à 8 points : il faut une information concrète (absence d'un titulaire clé, rotation annoncée, contexte particulier).
- Écart de plus de 8 points : exceptionnel. Vérifie deux fois ; le plus souvent, c'est toi qui te trompes.

## 2. Le modèle donne un deuxième avis

`p_model` (Dixon-Coles) ne connaît que les buts marqués et encaissés. S'il diverge fortement du marché, cherche pourquoi (transfert, blessure longue, changement d'entraîneur) avant de le suivre.

## 3. Ce qui fait bouger une probabilité

Par ordre d'importance : absences confirmées de joueurs clés (gardien, buteur, meneur), compositions probables, enjeu (maintien, qualification, match sans enjeu), fatigue (match européen trois jours avant), conditions exceptionnelles. La forme récente compte peu : le marché l'intègre déjà.

## 4. Valeur

Valeur = ta probabilité × cote simulée − 1. Elle doit atteindre 0,05. Une forte valeur sur un outsider vient presque toujours d'une erreur d'estimation : demande-toi ce que le marché sait et que tu ignores.

## 5. Liste des biais à vérifier avant chaque pari

- Récence : un gros score la semaine dernière ne change pas la force d'une équipe.
- Récit : « ils sont en mission » n'est pas une information.
- Grande équipe : la notoriété n'est pas une probabilité.
- Confirmation : cherche activement ce qui contredit ton idée.
- Tilt : après des pertes, ne cherche pas à te refaire ; le code limite tes mises, pas ton jugement.
- Petit échantillon : 3 cas ne font pas une règle.

## 6. Discipline des sources

Cite seulement ce que tu as réellement utilisé. Préfère les sources primaires (communiqués des clubs, conférences de presse, journalistes accrédités) aux forums et aux pronostiqueurs. Une source jetée ne revient pas. Une nouvelle source par jour au maximum.

## 7. Quand ne pas parier

Pas d'information nouvelle, doute sur une absence, écart avec le marché que tu ne sais pas expliquer, ou valeur juste au-dessus du seuil sans conviction : tu donnes ta prévision et tu ne paries pas.
```
